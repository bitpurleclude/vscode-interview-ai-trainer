# 练习页布局规划（Practice Page Layout Plan）

## 目标
- 全页面统一布局规划：顶部操作区 → 状态区 → 题干/题目区 → ResultsPanel
- 状态区改为三列网格，按指定顺序固定展示
- 面试评价整行展示，实时输出三列横排；未运行且无输出时不渲染三列框
- 小屏幕保持可用：状态区按断点降列数，面试评价实时输出在小屏用横向滚动查看
- 面试评价实时输出列数按题目数量动态展示（不足 3 时按实际数量）
- 保持现有功能与交互逻辑不变，仅调整布局与展示逻辑

## 整页布局顺序（最终）
1. 顶部操作区
2. 状态区（按三列网格）
3. 题干/题目区（进度条、音频时长、thinking、题干/题目输入、笔记命中）
4. ResultsPanel（转写 / 声学 / 评价 / 历史）

## 状态顺序（step id）
1. init（初始化）
2. recording（录音中）
3. acoustic（声学分析）
4. question（题目解析）
5. segment（多题分析）
6. asr（语音转写）
7. evaluation（面试评价）
8. notes（笔记学习）
9. report（结果生成）
10. write（文件写入）

## 响应式规则（页面大小变化）
- 状态区列数：
  - ≥1200px：3 列
  - 900–1199px：2 列
  - <900px：1 列
- 面试评价实时输出（三列卡片）：
  - 默认三列横排
  - <900px：保持横排，但容器允许横向滚动查看（显示滚动条）

## 组件修改清单（按文件）
### 1) `interview-trainer/webview/src/components/practice/PracticeFlow.tsx`
- 取消左右分栏结构，改为单列容器
- 状态区（StepsList）放在上方
- 进度条 / 音频时长 / thinking / 题干输入 / 题目列表 / 笔记命中 放在状态区下方
- 保持原有交互逻辑不变

### 2) `interview-trainer/webview/src/components/practice/StepsList.tsx`
- 固定步骤顺序为“状态顺序（step id）”中的列表
- evaluation 行整行全宽（grid-column: 1 / -1）
- evaluation 实时输出框仅在以下任一条件成立时显示：
  - 任意题目有输出文本
  - evaluation 步骤状态为 running
- 题目数不足 3 时，按题目数动态展示列数
- 其他步骤的实时输出（StreamCard）逻辑不变

### 3) `interview-trainer/webview/src/components/StreamCard.tsx`
- 如评价卡片在三列布局中显得拥挤，补充最小样式微调（留白/字号/行高）
- 无需改动逻辑

### 4) `interview-trainer/webview/src/styles.css`
- `.it-flow` 改为单列布局
- `.it-steps` 改为三列网格（gap、卡片高度一致）
- `.it-step--evaluation` 设置整行跨度（grid-column: 1 / -1）
- `.it-evaluation__stream-grid` 默认三列横排
- 小屏幕时 `.it-evaluation__stream-grid` 开启横向滚动
- 适配 `.it-question` / `.it-progress` / `.it-thinking` 的上下间距

## 展示规则
- 面试评价整行始终显示标题与状态
- 评价实时输出（三列卡片）仅在有输出或运行中时显示
- 题干/题目区位于状态区下方
- ResultsPanel 顺序不变（转写 / 声学 / 评价 / 历史）

## 风险与注意
- 步骤排序由前端强制排序，需确保 step id 在状态列表中完整覆盖
- 若新增步骤，需要同步更新“状态顺序”列表
- 样式变更需验证小屏与大屏显示效果

## 验收清单
- 状态区三列布局正确，顺序与示意一致
- 面试评价整行显示，三列实时输出在有内容时出现
- 题干/题目区位于状态区下方
- 小屏幕可用（状态区降列数，评价实时输出可横向滚动）
- 其他功能不受影响（录音、识别题目、笔记命中、结果展示）
