# 项目隐患列表

更新时间：2026-02-06
范围：vscode-interview-ai-trainer（含 interview-trainer 子项目）
来源：`interview-trainer/REVIEW_ISSUES.md`、`interview-trainer/ARCH_REFACTOR_PLAN.md`、`interview-trainer/REFACTOR_TASKS_PLAN.md`、`SPLIT_REFACTOR_PLAN.md`、配置与构建信息。

## 一、已知未解决问题（来自 REVIEW_ISSUES）

### 中
- 检索查询缓存 key 仅含 workspaceRoot/sourceCount/corpus.length，内容变更但数量不变时会命中旧缓存。`interview-trainer/src/interviewTrainer/core/analyze/flow.ts`
- 千帆 LLM baseUrl 无规范化，完整路径会重复拼接。`interview-trainer/src/interviewTrainer/api/it_qianfan.ts`
- 火山标准版轮询遇到非空文本即结束，状态未完成可能提前返回。`interview-trainer/src/interviewTrainer/api/it_volc_asr.ts`
- Unicode slug 未处理尾随空格/点号与 Windows 保留名。`interview-trainer/src/interviewTrainer/utils/it_text.ts`
- 语料目录监听使用 RelativePattern 可能导致绝对路径失效。`interview-trainer/src/interviewTrainer/core/it_configSnapshot.ts`
- 取消分析仅设置 abort 标记，ASR 分片/LLM 调用未检查。`interview-trainer/src/interviewTrainer/core/analyze/flow.ts`
- Baidu ASR 仅 PCM 分片，WAV/M4A 直接整段发送易超限。`interview-trainer/src/interviewTrainer/core/analyze/asr.ts`
- 超长段落不再继续切分，易超输入上限。`interview-trainer/src/interviewTrainer/core/notes/utils.ts`
- answers 仅在数量完全匹配时生效，部分回答会丢弃。`interview-trainer/src/interviewTrainer/core/analyze/flow.ts`
- Webview 请求超时不通知后端取消。`interview-trainer/webview/src/messenger.ts`, `interview-trainer/webview/src/hooks/useAnalysisFlow.ts`
- 后端未限制并发分析请求，可能并行多次分析。`interview-trainer/src/interviewTrainer/core/it_analysisFlow.ts`
- skipMtimeCheck 分支读缓存未做大小保护。`interview-trainer/src/interviewTrainer/core/notes/indexer.ts`
- 主题目录基于截断 slug，同日同前缀可能复用目录。`interview-trainer/src/interviewTrainer/storage/it_sessions.ts`
- 逐题检索/评价使用 Promise.all，多题易触发限流。`interview-trainer/src/interviewTrainer/core/analyze/flow.ts`
- LLM 分段 JSON 仅截取首尾花括号，解析易失败。`interview-trainer/src/interviewTrainer/core/analyze/shared.ts`
- 火山 ASR flash 模式不分片，长音频仍单次请求。`interview-trainer/src/interviewTrainer/core/analyze/asr.ts`
- Embedding 响应数组缺失向量时不校验数量。`interview-trainer/src/interviewTrainer/api/it_embedding.ts`
- 任一题号缺失即返回空数组，导致题目时间轴缺失。`interview-trainer/src/interviewTrainer/core/analyze/questions.ts`
- LLM/Embedding 请求重试未设默认值，undefined 时不重试。`interview-trainer/src/interviewTrainer/api/it_llm.ts`, `interview-trainer/src/interviewTrainer/api/it_embedding.ts`
- 导入音频无体积限制，整文件解码可能卡死/内存暴涨。`interview-trainer/webview/src/hooks/useAudioCapture.ts`
- warmup 忙碌期直接 return 不重试，可能永久跳过。`interview-trainer/src/interviewTrainer/core/it_embeddingWarmup.ts`
- PCM 分片一次性构建全部 base64，长音频内存峰值高。`interview-trainer/src/interviewTrainer/core/analyze/audio.ts`
- 多题检索任一失败导致 Promise.all 整体失败。`interview-trainer/src/interviewTrainer/core/notes/search.ts`
- 向量检索出错会中断分析，缺少降级兜底。`interview-trainer/src/interviewTrainer/core/notes/search.ts`, `interview-trainer/src/interviewTrainer/core/analyze/flow.ts`
- Embedding 内存缓存无上限策略，长期运行可能内存增长。`interview-trainer/src/interviewTrainer/core/notes/cache.ts`
- 火山标准版 status=success 但文本为空时返回空串。`interview-trainer/src/interviewTrainer/api/it_volc_asr.ts`
- timeoutSec 未校验有效数值，0/NaN 可能导致立即失败。`interview-trainer/src/interviewTrainer/api/it_llm.ts`, `interview-trainer/src/interviewTrainer/api/it_embedding.ts`, `interview-trainer/src/interviewTrainer/api/it_qianfan.ts`
- attempts.json 读-改-写无锁，多并发可能覆盖丢失。`interview-trainer/src/interviewTrainer/storage/it_sessions.ts`

### 低
- Webview 样式使用 color-mix，旧版 VS Code/Chromium 不兼容。`interview-trainer/webview/src/styles.css`
- Webview request 超时只 resolve 错误对象，部分调用未检查 status。`interview-trainer/webview/src/messenger.ts`, `interview-trainer/webview/src/InterviewTrainer.tsx`
- it_postWithRetries 无退避延时，易触发限流。`interview-trainer/src/interviewTrainer/api/it_volc_asr.ts`
- 会话目录日期使用 UTC，跨时区临界可能归档到前/后一天。`interview-trainer/src/interviewTrainer/storage/it_sessions.ts`
- 导入音频只取 channel 0，右声道丢弃。`interview-trainer/webview/src/hooks/useAudioCapture.ts`
- 题目解析启发式仅识别“第N题/问”格式。`interview-trainer/src/interviewTrainer/core/it_questionParser.ts`
- 按时间段取答案使用“重叠即归属”，跨题边界可能重复收录。`interview-trainer/src/interviewTrainer/core/analyze/questions.ts`
- LLM 分段 mapping 未校验 questionIndex 范围。`interview-trainer/src/interviewTrainer/core/analyze/questions.ts`
- 异常分支使用“?????”占位，提示不可读。`interview-trainer/src/interviewTrainer/core/it_analysisFlow.ts`
- 历史记录找不到目标报告时取最新 md，可能误打开。`interview-trainer/src/interviewTrainer/storage/it_history.ts`
- 新一轮分析开始未清空 analysisResult，处理中仍展示上次结果。`interview-trainer/webview/src/hooks/useAnalysisFlow.ts`
- 打开报告未检查返回状态，失败无提示。`interview-trainer/webview/src/InterviewTrainer.tsx`
- 加载历史列表失败无反馈。`interview-trainer/webview/src/hooks/useAnalysisFlow.ts`
- 音频转换 fallback 默认超时 60s，易掩盖真实错误。`interview-trainer/webview/src/messenger.ts`
- convertAudioToPcm 失败时不清理临时目录。`interview-trainer/src/interviewTrainer/handlers/it_webviewRecordingHandlers.ts`
- 检索缓存 key 仅取前 300 字符，长文本易碰撞。`interview-trainer/src/interviewTrainer/core/notes/cache.ts`
- 题目解析 JSON 提取仅首尾 {}，多段 JSON 易失败。`interview-trainer/src/interviewTrainer/core/it_questionParser.ts`
- 千帆 baseUrl 为空仍拼路径，报错不直观。`interview-trainer/src/interviewTrainer/api/it_qianfan.ts`
- it_nextAttemptIndex 按 ## 标题计数，正文同级标题会误增。`interview-trainer/src/interviewTrainer/storage/it_sessions.ts`

## 二、架构与维护风险

- 当前架构边界混杂，Interface/Application/Domain/Infra 仍处迁移阶段。`interview-trainer/ARCH_REFACTOR_PLAN.md`
- 协议文件 `src/protocol/interviewTrainer.ts` 是否拆分仍未决，类型同步风险待评估。`interview-trainer/REFACTOR_TASKS_PLAN.md`
- 仍存在大量“导出但未被引用”的符号清单，清理不当可能引入回归。`interview-trainer/CLEANUP_PLAN.md`
- 历史大文件拆分计划需阶段验证，变更范围大、回归风险高。`SPLIT_REFACTOR_PLAN.md`

## 三、依赖与打包风险

- 依赖 `ffmpeg-static`，打包若未包含 `node_modules/ffmpeg-static` 将导致录音/转写失败。`AGENTS.md`
- npm audit 存在中危漏洞（esbuild/vite 链），修复需 `npm audit fix --force`（破坏性升级）。

## 四、配置与密钥风险

- Provider 模板配置中的 `secret_key` 默认为空，若未正确配置会导致 ASR/LLM 调用失败。`interview-trainer/config/providers/*.yaml`
